# Виталий Гуцелов — моя история

Сайт-биография. Один файл `index.html`, без сборки и зависимостей.

## Публикация на GitHub Pages
1. Создай репозиторий на github.com (Public).
2. Загрузи в него `index.html`, `.nojekyll` и `README.md`.
3. Settings → Pages → Source: Deploy from a branch → Branch: main, папка /(root) → Save.
4. Через 1–2 минуты сайт откроется по адресу https://ТВОЙ-НИК.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/
